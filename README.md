# 刷题器 · 通用版（内置考研英语二真题 · AI 解析）

一个可以公开分享的通用刷题器：**内置 2010-2026 共 17 套考研英语二真题**（题目、文章与答案为公开流传版本；**解析、参考译文与范文全部为 AI 生成**，不含任何原版解析书内容），另附一套纯 AI 演示题库（`data/demo.js`），并支持**拖拽导入任意科目的自建题库**——通用规范支持单选/多选/判断/填空/匹配/排序/选词填空/主观题八种题型，客观题自动评分；内置 KaTeX 公式渲染，政治、专业课、数学等科目同样适用。

---

1. **版权边界**：历年考研真题版权归教育部教育考试院。本项目仅收录题目、文章与答案（公开流传版本），**逐题解析、整体解析、参考译文、范文均为 AI 生成，不包含任何原版解析书/官方解析的文字**。如权利方提出异议，请联系仓库所有者删除相应内容。
2. **质量提示**：AI 解析为**简版**（词义辨析、定位思路、同义转述说明），不保证达到官方解析的深度与准确性。参考译文与范文也是 AI 生成，仅供参考对照。
   **想要高质量深度解析？自己动手**：把你的资料（任何 Word/PDF）交给 AI，用下面的提示词模板生成专属题库，然后拖入刷题器即可——并与 AI 生成的简版解析逐题核对。

## 快速开始

1. 双击 `index.html`（任意现代浏览器，无需安装）。
2. 直接刷内置的「AI 模拟卷」。
3. 有自己的题库？把 `.js` / `.json` 文件**拖到首页的虚线框里**，即导入完成，题库会自动保存在浏览器本地。
4. 删除自建题库：首页对应卡片上的「删除此题库」按钮。

> 导入的题库保存在浏览器 localStorage（约 5MB 上限，单套题库建议 < 4MB，可存多套）。换电脑/换浏览器前，用首页「⬇ 导出全部」备份（题库 + 做题记录 + 错题本一起导出），新环境「⬆ 导入备份」恢复。

## 如何把网上的 Word / PDF 做成题库

### 工作流一（推荐）：AI 直接生成题库文件

**第 1 步**：把 Word/PDF 的内容（题目、文章、解析）发给任意 AI 助手（CodeBuddy、ChatGPT、Kimi 等），附上**《题库生成规则.md》全文**（与本 README 同目录，通用规范 v2：支持单选/多选/判断/填空/匹配/排序/选词填空/主观题八种题型、任意科目，客观题自动评分），AI 会直接输出一个 `.js` 文件。

> 原题材料**任何形式都可以**：PDF 复制的文本、Word 全文、拍照 OCR 的文字、网页内容，甚至多张截图的文字——一并粘给 AI 即可。规则文件里已包含乱序/OCR 错误修复、答案缺失时的处理、输出自检清单等。

**第 2 步**：把 AI 输出保存为 `xxx.js`，拖进刷题器。

**第 3 步**：**人工抽检 10-20 题**，核对答案与解析是否正确（AI 生成内容必须人工校验）。发现错误可把错题发回给 AI 修正后重新导入。

### 工作流二：先转 Markdown 再本地构建（适合批量、精细控制）

1. 让 AI 把 PDF/Word 转录成两份 Markdown（题目一份、解析一份，按标题分节）。
2. 参考主工程 `build_quiz_data.py` 的解析规则（题目文件用 `## Section I-IV` 分区，解析文件用速查表答案 + 逐题解析标记），把 md 接入构建脚本。
3. 运行脚本生成 `data/XXXX.js`，拖入刷题器或随 index.html 一起发布。

## 【AI 提示词模板】（复制给 AI，替换首行为你的资料）

```text
下面这份资料是我的英语练习材料（题目、文章、答案与解析）。请把它整理成
"刷题器题库数据文件"，只输出一个完整 .js 文件的代码（代码块内），不要任何解释文字。

【输出格式要求】严格遵循以下 schema（字段名、结构必须一致）：

window.QUIZ_DATA = window.QUIZ_DATA || {};
window.QUIZ_DATA[9002] = {
  year: 9002,                       // 题库编号（1000-9999，勿与已有题库重复）
  label: "我的题库名称",
  cloze: {                          // 完形填空（若无此类题则 questions: []）
    directions: ["Directions: ..."],
    passage: ["段落1（空格写作 __1__）", "段落2 ..."],
    questions: [
      { num: 1, stem: "", opts: { A: "选项内容", B: "...", C: "...", D: "..." },
        answer: "B",
        analysis: "考点：xxx。解析：空格处 ...，选[B]。" }
      // 共 N 题，num 从 1 连续递增
    ],
    analysisBlob: "**【完形整体解析】**全文主旨与解题思路（可简短）"
  },
  reading: [                        // 阅读理解（每篇一个对象）
    {
      title: "文章标题",
      passage: ["段落1", "段落2", "段落3"],
      overview: "文章总体分析：题材、结构、主旨（2-3 句）",
      discourse: "",                // 可留空
      questions: [
        { num: 21, stem: "题干",
          opts: { A: "...", B: "...", C: "...", D: "..." },
          answer: "C",
          analysis: "考点：细节题/推理题/态度题/词义题/主旨题。解析：定位到第 X 段 ...，排除 A/B/D 的理由。" }
      ]
    }
    // 依次每篇对象，num 全卷连续递增
  ],
  partB: {                          // 新题型（选择匹配或判断正误）
    directions: ["Directions: ..."],
    options: [ { key: "A", text: "选项A内容" }, ... ],  // 匹配题给 A-G；判断正误题给 []
    passage: ["原文段落（若有）"],
    questions: [
      { num: 41, stem: "题干/待匹配句", opts: {}, answer: "A",
        analysis: "对应 A：同义改写对照说明。" }
    ],
    analysisBlob: "**【Part B 整体解析】**..."
  },
  translation: {                    // 翻译（若无可整段省略此字段）
    blocks: ["Directions: ...", "——", "英文原文段落..."],
    reference: "参考译文（\\n 分段）",
    analysis: "翻译要点逐条说明"
  },
  writing: {                        // 写作（若无可整段省略此字段）
    small: ["Directions: 小作文题目"],
    small_ref: "参考范文",
    large: ["Directions: 大作文题目"],
    large_ref: "参考范文"
  }
};

【质量要求】
1. 所有文章、题干、选项、解析使用资料原文；资料中缺失解析的题目，基于答案写出简明解析（标注"解析为 AI 补写"）。
2. 每题 answer 必须是该题 opts 中真实存在的字母（partB 匹配题为 options 中的 key）。
3. num 全卷连续、无重复；选项数固定（完形/阅读 4 个，新题型按资料）。
4. 输出前自检：统计各类题数并核对答案分布是否合理；确认 JSON 无语法错误（引号转义、逗号）。
5. 若资料不完整（缺某部分），省略对应字段，不要编造整段原文。
```

> 提示：`9002` 换成任意未占用的编号；`label` 换成你的题库名。一次资料太多可分卷（9002、9003……）逐个生成。

## 导入文件的两种合法形态

| 文件内容 | 说明 |
|---|---|
| `window.QUIZ_DATA[9002]={...};` | AI 提示词模板直接输出的形态（推荐） |
| `{ "year": 9002, "label": "...", "cloze": {...}, ... }` | 纯 JSON 形态，同样支持 |

校验失败会弹窗提示——说明 schema 不符，把报错和 README 的模板一起发给 AI 修正即可。

1. 在 GitHub 网页新建仓库（如 `kyz-quiz-open`）。

   git add .

## 已知限制

- 题库存于浏览器 localStorage（约 5MB），超大题库请拆分；换浏览器/清缓存会丢失，请用「导出全部」备份。
- 题库结构以本 README 的 schema 为准；完形/阅读/新题型三类为判分题，翻译/写作类为自评对照。
- AI 生成的答案可能出错——**逐题核对是使用自建题库的必要环节**。
